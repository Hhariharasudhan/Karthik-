# Background Music Directory 🎵

Place your background music file here!

Recommended file:
- `sita-ramam-bgm.mp3` (or `our-song.mp3`)

Instructions:
1. Download your favorite audio track (e.g. *Sita Ramam* 2022 film background music).
2. Save it as `sita-ramam-bgm.mp3` inside `src/assets/music/`.
3. In `src/data/loveStory.ts`, ensure `musicUrl` is set to:
   `musicUrl: "/src/assets/music/sita-ramam-bgm.mp3"`

Note: If no audio file is provided, the website automatically synthesizes a dreamy, romantic ambient music-box melody using Web Audio API so it will never stay silent!
